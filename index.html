📌 專案摘要 (Executive Summary)

智能扣帳方查詢系統 (展示版) 是專為企業營造地盤現場突發事件與合約合規設計之現代化智能輔助原型工具。

本專案針對工程開單與責任劃分之痛點，運用本地語意嵌入向量庫（Local Dense Vector Matching with FAISS）與同義詞擴展技術，在前線工程團隊輸入日常口語或地盤俗語時，自動對齊企業通用指引《使用扣帳方題庫.xlsx》，精準判定扣帳分類代號，實現規範化開單、減省爭議並從底層設計消除黑箱 AI 幻覺風險。

🏛 檢索流程與語意對齊架構 (Workflow Architecture)

系統結合確定性文字匹配與多語言向量距離計算，確保前線地盤情境即時轉化為嚴謹之合約責任依據：

步驟 1・數據載入
Excel 臨時記憶體解析
直接讀取內部官方題庫，數據僅保留於瀏覽器當次工作階段（Session），徹底杜絕外部持久化洩漏。
步驟 2・語意擴展
地盤口語雙向轉譯
自動將「執修」、「肥佬」、「買錯料」、「罰款」等前線俗語映射至合約專業標準術語。
步驟 3・本地檢索
FAISS 零外連比對
全流程於本地邊緣端完成，完全切斷第三方生成式 AI 接口，確保商業機密零出境。
步驟 4・確定輸出
條文原樣呈現與置信評估
精確回顯題庫原始行數紀錄與比對信心分數，維持 100% 可解釋性與審計追蹤能力。

📋 扣帳分類與權責矩陣 (Charge Code Classification Matrix)

扣帳類型代號 適用範疇 典型地盤情境 管治審計重點
Type-A (行政費用) 主判扣除、地盤罰款、公共雜費 地盤吸煙罰款、未戴安全帽扣款、清理廢料垃圾費用等。 須具備大判 Debit Note 或書面通知憑證，釐清內外責任分攤。
Type-I (安裝修正) 施工瑕疵、重做、工序調整 安裝尺寸偏差重做、內部圖紙出錯導致重裝、拆卸重修等。 區分內部失誤或分判商過失，作為工資與分判工程款沖銷依據。
Type-M (物料重購) 材料採購失誤、現場損毀 操作不當導致材料報廢、規格買錯需重新訂購、配件遺失等。 核對材料採購合約與入庫簽收單，追蹤物料耗損責任歸屬。
Supplier (供應商扣帳) 第三方責任、出廠瑕疵 廠家出貨不合格需地盤代工執修、分判商施工失誤由他判代辦等。 落實連工包料與供應合約之代工扣款通知及背靠背索償程序。

⚙️ 技術亮點與 ISO 合規 (Technical & Governance Highlights)

1. 極致數據隱私 (Zero Data Retention)

貫徹 ISO/IEC 42001 Annex A.6.2 數據最小化要求，題庫僅在當前會話記憶體中運算，關閉視窗即全量銷毀，不存任何後端資料庫。

2. 防洩漏實體隔離 (Air-Gapped Embedding)

完全切斷任何第三方生成式 AI API 呼叫，全流程本地向量化處理，嚴格滿足 ISO/IEC 27001 A.8.12 數據洩漏防禦標準。

3. 確定性輸出與抗幻覺 (Zero Hallucination)

比對結果直接對齊內部原始 Excel 行數與文字，不具備自主編造文本能力，具備 100% 可解釋性（Explainability）與可追溯性。

4. 人工監督閉環 (Human-in-the-Loop)

系統定位為輔助決策支援工具，扣帳單最終確認與財務結算由權責主管核定，滿足 ISO 42001 A.8.3 人工介入與問責機制。
